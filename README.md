# Projeto-Chat-Bot-IA-com-Streamlit
# Chatbot de IA com Streamlit

Projeto desenvolvido em Python utilizando Streamlit e uma API de Inteligência Artificial.

## Funcionalidades

- Interface de chat com Streamlit
- Histórico de mensagens
- Integração com modelo de IA
- Uso de session_state para memória da conversa

## Tecnologias

- Python
- Streamlit
- OpenAI SDK
- Gemini API

  Usuário escreve
        ↓
Mensagem é salva
        ↓
Histórico vai para a IA
        ↓
IA responde
        ↓
Resposta aparece na tela
        ↓
Resposta também é salva
